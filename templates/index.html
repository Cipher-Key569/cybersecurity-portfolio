PROJECT 04 HARDWARE / PYTHON / FASTAPI

RFID Time Tracker

A full-stack RFID work-session tracking system built with Arduino, RC522 RFID, Python, SQLite, and FastAPI.

Arduino RFID Python FastAPI SQLite REST API

Objective

Build a local hardware-based system that tracks work sessions using RFID authentication while providing real-time status and reporting through a web dashboard.

Architecture

Arduino Mega reads RFID cards through an RC522 module and sends authenticated events over USB serial. A Python listener processes the events, stores session data in SQLite, and exposes the data through a FastAPI backend.

Hardware

  • Arduino Mega
  • RC522 RFID reader
  • RFID cards / tags
  • Buzzer
  • Breadboard and USB connection

Software

  • Python
  • FastAPI
  • SQLite
  • HTML / CSS / JavaScript
  • REST API

Security Considerations

Implemented authorized-card validation and unauthorized access detection. The public repository uses sanitized example identities, worker IDs, and RFID UIDs to prevent sensitive information from being exposed.

Outcome

Created a functional local time-tracking platform with RFID sign-in/sign-out, break tracking, session history, reporting, net work-time calculations, and a live web dashboard.
